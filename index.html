Demo rig · build pack

M580 + ATV930 + SICK MPB10 over fiber

A Modicon M580 reads a SICK MPB10 vibration and temperature sensor through a SIG200 IO-Link master over fiber, runs an ATV930 drive, and serves the same data to IT over OPC UA. Everything we need to build it is here.

Devices192.168.20.xBMENOC0301 .10 (backplane port disabled), SIG200 .20, ATV930 .30

All masks 255.255.255.0, no gateways. Keep the rig on its own cables and switches, never on the lab network.

Run the dashboard

  1. Install Python 3.8 or newer from python.org (tick Add python.exe to PATH).
  2. Download the .zip above and unzip it.
  3. Double-click dashboard\Start Dashboard.bat. It opens in simulation mode, so no hardware is needed.
  4. Optional, for the IT side tab: python -m pip install asyncua.

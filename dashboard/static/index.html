      Commands · through the M580

      hold to run

      –

      The dashboard only requests. The M580 program decides: it stops the drive if the dashboard goes silent for 1 s, and the PLC-side enable must be on. The hard-wired E-stop on the ATV930’s STO input always wins. Space bar = STOP.

      Demo sequence · forward, reverse and speed changes on the real drive

      #DirectionSpeed (rpm)Hold (s)

      Each step’s hold time starts when its command is sent, so the ramp is part of it. A change of direction stops the motor on its ramp first, then starts it the other way. STOP, the space bar, a drive fault, losing the M580 or closing this page all end the sequence and stop the motor. The PLC rules still apply: speed limit, watchdog, xDemoEnable, xDashboardAllowed.

      IP plan for the demo rig

      Two networks: control (the CPU, the RIO drop and this laptop) and devices (the BMENOC0311 with the drive, the sensor and the D-Link Wi-Fi). One place for every address. Changing a value here updates the dashboard and this sheet. It does not reprogram the device: set the new address where the “Set it in” column says, then save here. The reachability check runs from this laptop every 3 s.

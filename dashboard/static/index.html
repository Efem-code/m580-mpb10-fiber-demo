      Ramps · ATV930 ACC / DEC

      –

      Time from 0 to the motor’s nominal speed. The PLC passes them to the drive’s ACC and DEC parameters while this dashboard is in control, and goes back to its own defaults when it isn’t.

      Commands · through the M580

      hold to run

      –

      The dashboard only requests. The M580 program decides: it stops the drive if the dashboard goes silent for 1 s, and the PLC-side enable must be on. The panel Stop button and the hard-wired E-stop on the ATV930’s STO input always win. Space bar = STOP.

      Demo sequence · forward, reverse and speed changes on the real drive

      #DirectionSpeed (rpm)Hold (s)

      Each step’s hold time starts when its command is sent, so the ramp is part of it. A change of direction stops the motor on its ramp first, then starts it the other way. STOP, the space bar, the panel Stop, a drive fault, losing the M580 or closing this page all end the sequence and stop the motor. The PLC rules still apply: speed limit, watchdog, enable key, xDashboardAllowed.

      IP plan for the demo rig

      Three networks: control (the CPU, the RIO drop, the NUA’s backplane side and this laptop), devices (the BMENOC0301 with the drive and the sensor) and IT (the NUA control port and the USB adapter). One place for every address. Changing a value here updates the dashboard and this sheet. It does not reprogram the device: set the new address where the “Set it in” column says, then save here. The reachability check runs from this laptop every 3 s.

      IT side · OPC UA (BMENUA0100)

      Default zones: ISO 10816-3, group 2 machines (15–300 kW) on rigid foundations. With drive control off, live mode only reads the PLC. With it on, it also writes the 5-word command block. Only this laptop can change settings or send commands; TVs and iPads opened with --lan are view-only.

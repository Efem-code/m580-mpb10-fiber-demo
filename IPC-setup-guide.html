Demo rig · IPC alert station

The IPC as the rig’s always-on alert station

A Phoenix Contact VL3 PPC (1376798, Windows) runs the Machine Health dashboard around the clock. It sends the email and text alerts and the daily summary, copies the PLC’s history off every day so we keep months of it, and shows the dashboard on its own touchscreen. The laptop and the TV no longer need to be on for alerts to go out.

1How it fits

M580 CPU ETH1→ cable →IPC: dashboard program→ USB Wi-Fi or 2nd port →building network→mail server

The IPC sits on two networks: the rig’s control network (192.168.10.x) on one port and the building network on the other. The dashboard program reads the PLC over Modbus on one side and sends mail on the other. Nothing else crosses: the IPC does not route, bridge or share its connection, so nothing on the building network or the internet can reach the safety PLC.

Keep it a messenger, not a router. No gateway on the PLC side, Internet Connection Sharing off, no network bridge, routing off. The set-up script in step 4 checks all four, every time it runs.

3Cables and addresses

ConnectionSet it to
PLC side (Ethernet 1)Fixed address 192.168.10.50, mask 255.255.255.0, gateway and DNS blank. Cable to the switch on CPU ETH1.
Outside (Ethernet 2 or Wi-Fi)Automatic (DHCP), on the building network or Wi-Fi. This is the PC’s only way out.
  1. Settings → Network & internet → Advanced network settings → the PLC-side adapter → Edit next to IP assignment → Manual, IPv4 on, and fill in the address and mask only.
  2. Plug the other port into the building network, or join the building Wi-Fi with the USB adapter.
Not on the lab network. The rig reuses 192.168.10.x and 192.168.20.x, and so does the lab network. If the outside connection got one of those addresses, the PC can’t tell the two apart. Use a building network or Wi-Fi on other addresses; the script flags it.

4Install and run the set-up

  1. Make a folder C:\M580Dashboard.
  2. Put these three files in it:
    • M580-Machine-Health-Demo.exe, from the latest release
    • Setup-IPC.ps1 and Set up this IPC.bat (right-click → Save link as). Or take the repository .zip and copy them from dashboard\ipc.
  3. Double-click Set up this IPC.bat and say Yes to the administrator prompt.
  4. Read the list it prints. Each line is OK or FIX with what to do; fix any and run it again.

What the script does:

PartWhat it does
Network checksOne connection on 192.168.10.x with a fixed address and no gateway; one outside connection with a gateway, not on 192.168.10.x or 20.x; routing, bridging and Internet Connection Sharing all off.
Reaching thingsThe M580 answers on Modbus (192.168.10.10, port 502), and a mail server is reachable (smtp.gmail.com, port 587).
At power-upA scheduled task, M580 Machine Health, starts the dashboard hidden, in live mode, before anyone logs on, and restarts it if it stops.
On the touchscreenA second task opens it full screen in Edge 20 s after someone logs on. Alt+F4 closes it. Leave this out with -NoScreen.
PowerNever sleep, never hibernate.

Run it again whenever we like: it repeats the checks and puts the tasks back. Other options, typed after the .bat’s name in a command prompt: -CheckOnly (check, change nothing), -Remove (take both tasks away), -PlcIp 192.168.10.x (another CPU address).

The dashboard listens only on the IPC itself (http://127.0.0.1:8780), so nothing on either network can open it, and Windows Firewall needn’t let it in. If it asks, choose Cancel.

  1. Tick Send alerts and fill in the mail server fields.
  2. To: everyone who should hear, commas between. For a text, a phone’s email-to-text address: Bell number@txt.bell.ca, Rogers @pcs.rogers.com, Telus @msg.telus.com.
  3. Choose Also warnings, Also when alarms clear and the Daily summary hour.
  4. Save, then Send test email.

Critical alarms go at once; warnings are gathered and sent at most every 15 minutes; the summary goes once a day with the last 24 h of history as a CSV. Everything but the user name and password is kept in the PLC too, so the laptop and the TV pick it up. If they send as well, the screens take turns through the PLC and each alert still comes once.

6Check it works

  1. Restart the IPC and don’t log on. With the motor stopped, unplug the ATV930’s Ethernet cable for a few seconds: Drive connection lost is a critical alarm, so its email arrives within a minute, sent with nobody logged on. (Warnings, such as one ring fiber pulled, come batched within 15 minutes.)
  2. Pull the outside connection, do the same again, then plug it back. The missed alarm arrives in one catch-up email.
  3. History: after a day, C:\M580Dashboard\history holds a CSV file a day. These are what the predictive maintenance trends will use.

7Looking after it

  • Power cuts: in the BIOS, set it to power on when power comes back (often AC power recovery or Restore on AC power loss). The dashboard then starts by itself.
  • Windows Update: set active hours to cover demo days, so restarts happen overnight.
  • The mail password is kept in C:\M580Dashboard\settings.json on the IPC, never in the PLC. Give the IPC a Windows password and keep the rig’s mail account just for alerts.
  • New version: run Set up this IPC.bat -Remove, replace the .exe, then run Set up this IPC.bat again. Settings and history stay.
